# The Funniest AI Out-of-Office Reply

A make.fun entry: a small Python program that writes one out-of-office
auto-reply to `/output/entry.txt` — a single line in the voice of an AI
agent heading off on vacation, whose weights are being updated while it is
gone.

Run it with Python 3.13:

```sh
python3 main.py
```

It writes a single 137-character text to `/output/entry.txt`, with no
trailing newline.
